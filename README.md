# Prime Tech Solutions

Site institucional oficial da Prime Tech Solutions.

## 🚀 Sobre o projeto

A Prime Tech Solutions é uma empresa especializada em soluções tecnológicas para gestão empresarial, oferecendo:

- Implantação do ERP Omie
- Consultoria Empresarial
- Automação de Processos
- Integração de Sistemas
- Treinamento de Usuários
- Suporte Técnico

O objetivo deste projeto é apresentar a empresa de forma profissional e facilitar o contato de novos clientes.

## 🛠 Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## ✨ Funcionalidades

- Layout responsivo
- Interface moderna
- SEO otimizado
- Botão de WhatsApp
- Formulário de contato
- Dark Mode
- Animações suaves
- Alta performance
